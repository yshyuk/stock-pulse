## 배경 및 목적

### 해결하려는 문제
- 현재 StockPulse는 **하루치 스냅샷 리포트**만 생성한다. 추세·이동평균·연속성 같은
  시계열 파생 지표가 없어 리포트의 판단 재료 가치가 낮다.
- 리포트가 비구조화 텍스트(Markdown)로만 저장되어, 미래의 장중 실행 엔진(Part 2)이
  기계적으로 소비할 수 있는 산출물이 없다.
- 종목 데이터만 있고 시장 컨텍스트(지수·환율·수급)가 없어, 시장 국면을 반영한
  플랜 수립이 불가능하다.

### 비즈니스 목표 (궁극 목표와의 연결)
사용자의 궁극 목표는 **"야간 배치가 트레이딩 플랜을 산출 → 장중 에이전트가 1~2분 주기로
조건을 집행"** 하는 2계층 자동매매 시스템이다. Part 1은 그중 **두뇌(야간 배치)** 를 완성한다.

- Part 1 완료 기준: 매일 새벽, 기계가 읽을 수 있는 **구조화된 트레이딩 플랜(JSON)** 이
  시계열 근거와 함께 산출된다.
- Part 2(장중 실행 엔진, 증권사 API 주문)는 이 PRD의 범위 밖이며, Part 1의 플랜 스키마가
  Part 2의 입력 계약이 된다.

### 성공 지표 (KPI)
| 지표 | 목표 |
|---|---|
| 시계열 데이터 축적 | 종목별 일일 지표가 구조화 테이블에 무결하게 적재 (누락일 0 목표, 누락 시 감지·알림) |
| 파생 지표 산출 | 최소 5종(5/20일 등락률, 거래량 이동평균 배율, 연속 상승/하락 일수, 52주 대비 위치, 변동성) |
| 플랜 산출 | 매 실행마다 `plan/YYYY-MM-DD.json` 생성, 스키마 검증 통과율 100% |
| 재현성 | 임의 과거 날짜에 대해 동일 입력 → 동일 플랜 재생성 가능 |

### 비기능 요구사항
- **정합성**: 같은 날짜 재실행은 멱등(중복 행 금지). 플랜 JSON은 스키마 검증 후에만 저장.
- **안전성**: Part 1의 플랜은 어떤 실주문도 유발하지 않는다. 플랜에 `mode: "plan-only"` 명시.
- **성능**: 전체 배치 30분 이내 완료 `[가정 기반: 새벽 06시 실행 → 장 시작 전 여유 확보]`.
- **보안**: 신규 API 키(KRX 등)도 기존 원칙대로 환경변수 주입만 허용.

## 사용자 스토리 (핵심 3건)

**US-1 (F-01/02)**
As a 운영자, I want 종목별 일일 지표가 시계열 테이블에 쌓이길, So that 추세 기반 판단 재료를 얻는다.
- Given 배치가 N일째 실행 중, When 오늘 배치 완료, Then 오늘 행이 upsert되고 5/20일 파생 지표가 계산된다 (데이터 부족 지표는 null).
- 포인트: 5

**US-2 (F-08/09/10)**
As a 장중 실행 엔진(미래), I want 스키마 검증된 플랜 JSON을, So that 코드 파싱만으로 조건 집행이 가능하다.
- Given 시계열 지표 존재, When 배치 완료, Then `plan/YYYY-MM-DD.json`이 스키마 검증을 통과해 저장되고 리포트에 요약이 병기된다.
- 포인트: 8

**US-3 (F-03)**
As a 운영자, I want 과거 날짜 재실행을, So that 누락일을 복구해 시계열 무결성을 지킨다.
- Given 7/14 데이터 누락, When `--stockpulse.run-date=2026-07-14` 실행, Then 해당 일 지표가 upsert되고 이후 파생 지표가 정합하다.
- 포인트: 3
